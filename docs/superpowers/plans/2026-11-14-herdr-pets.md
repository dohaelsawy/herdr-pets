# herdr-pets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public Herdr app mod that shows the vscode-pets animals as decorative pets in a sidebar panel.

**Architecture:** One mod folder, `mods/pets/`. Seven pure modules (`pets.js` generated tables, `engine.js`, `gif.js`, `store.js`, `sources.js`, `artcore.js`, `roster.js`) hold everything testable and run under `node --test`. Three Herdr-facing modules (`art.js`, `dialogs.js`, `main.js`) hand Herdr's file and program access to the loader and do the drawing. A pet's state becomes one *leg* that Herdr's native transition animates; a 200 ms check starts the next leg and redraws only then.

**Tech Stack:** Plain JavaScript (ES modules, no build step, no dependencies). Herdr app mods (gpui-kit). Node 22+ for tests (`node --test`). `herdr-app check` for the mod.

**Spec:** `docs/superpowers/specs/2026-11-14-herdr-pets-design.md`

## Global Constraints

- Repo root is `~/herdr-pets`. Run every command from there unless a step says otherwise.
- **No art in the repo, ever:** no GIF or PNG sprite in the working tree, in git history, or in test fixtures. Tests build their GIFs in code. `preview.png` (a screenshot) is the only image, and it shows no cat, frog, bunny or squirrel.
- No dependencies. `package.json` has no `dependencies` or `devDependencies`.
- `engine.js`, `gif.js`, `store.js`, `sources.js`, `artcore.js`, `roster.js` and `pets.js` must not import `herdr`, `gpui-kit`, `gpui-base` or `fs/promises`.
- `mods/pets/pets.js` is generated by `scripts/gen-pets.mjs`. Never edit it by hand.
- Upstream is pinned to tag `1.37.0` of `tonybaloney/vscode-pets`.
- Herdr rules for mod code: no DOM, no `setTimeout`/`setInterval` (use `cx.timer`), no top-level `await`, never keep a `cx` for later, animate with `.transition`/`.loop`, not a timer.
- A mod is not done until `herdr-app check mods/pets` prints `check passed`.
- Limits and defaults: 20 pets; sizes nano 30, small 40, medium 55, large 110 px; default size medium; default theme none; `mod.json` is `{ "place": "none", "title": "Pets" }` (the mod does not dock itself; the recipe puts a 110 px block in the sidebar above the footer).
- Herdr stops a script that runs about half a second without a break, uncatchably. No synchronous work may be long: `gif.js` works in steps of `SLICE` pixels and the loader pauses for the app between them.
- Commit after every task. End each commit message with:
  `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`
- Nothing is pushed to GitHub until the owner says so (Task 9).

`scripts/gen-pets.mjs`:

```js
// Regenerates mods/pets/pets.js from a checkout of vscode-pets' source.
//   node scripts/gen-pets.mjs <path to vscode-pets/src> <tag>
// Reads TypeScript as text; it never executes upstream code.
import { readFileSync, readdirSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";

const [src, tag] = process.argv.slice(2);
if (!src || !tag) {
  console.error("usage: node scripts/gen-pets.mjs <vscode-pets/src> <tag>");
  process.exit(1);
}
const read = (p) => readFileSync(join(src, p), "utf8");

// `export const enum Name { key = 'value', ... }` -> { key: value }
function parseEnum(text, name) {
  const body = text.match(new RegExp(`enum ${name} \\{([\\s\\S]*?)\\n\\}`))?.[1];
  if (!body) throw new Error(`enum ${name} not found`);
  const out = {};
  for (const m of body.matchAll(/(\w+)\s*=\s*(?:'([^']*)'|(\d+))/g)) out[m[1]] = m[2] ?? Number(m[3]);
  return out;
}

const types = read("common/types.ts");
const COLOR = parseEnum(types, "PetColor");
const TYPE = parseEnum(types, "PetType");
const SPEED = parseEnum(types, "PetSpeed");
const STATE = parseEnum(read("panel/states.ts"), "States");

// v1 has no ball and no friends: these states are removed everywhere.
const DROPPED = new Set(["chase", "idle-with-ball", "chase-friend"]);

// What upstream does in code rather than data. Checked against 1.37.0.
const OVERRIDES = {
  finley: { bubble: "Hi! 👋" },
  horse: { bubble: "Neigh!" },
  skeleton: { bubble: "☠️", bubbleByColor: { orange: "🎃", warrior: "🏴‍☠️" } },
  squirrel: {
    bubbles: ["🌰?", "🍕?", "🥨?", "🥜?", "🥡?", "🍏?"],
    speedFactor: 1.15,
    climbSpeed: 5.5, // 7 px/tick with a variation averaging -1.5
    fallSpeed: 15,
    climbRange: [0.3, 0.8], // share of the panel height
  },
};

// class name -> speed, from createPet's switch
const speedOf = {};
for (const m of read("panel/pets.ts").matchAll(/return new (\w+)\(\.\.\.standardPetArguments, PetSpeed\.(\w+)\)/g)) {
  speedOf[m[1]] = SPEED[m[2]];
}

// The string literals in a piece of TypeScript, in order. It skips // comments, so an
// apostrophe in a comment (// Conker's Bad Fur Day) is not taken for a quote.
function strings(body) {
  const out = [];
  for (let i = 0; i < body.length; i++) {
    const c = body[i];
    if (c === "/" && body[i + 1] === "/") {
      while (i < body.length && body[i] !== "\n") i++;
    } else if (c === "'" || c === '"') {
      let text = "";
      for (i++; i < body.length && body[i] !== c; i++) text += body[i] === "\\" ? body[++i] : body[i];
      out.push(text);
    }
  }
  return out;
}

const pets = {};
for (const file of readdirSync(join(src, "panel/pets")).filter((f) => f.endsWith(".ts")).sort()) {
  const text = read(`panel/pets/${file}`);
  const cls = text.match(/export class (\w+) extends BasePetType/)?.[1];
  const label = text.match(/\n\s+label = '([^']+)'/)?.[1];
  if (!cls || !label) throw new Error(`${file}: no class or label`);
  if (!Object.values(TYPE).includes(label)) throw new Error(`${file}: ${label} is not a PetType`);
  if (!(cls in speedOf)) throw new Error(`${file}: no speed for ${cls}`);

  const colors = [...text.match(/static possibleColors = \[([\s\S]*?)\]/)[1].matchAll(/PetColor\.(\w+)/g)].map((m) => COLOR[m[1]]);
  const start = STATE[text.match(/startingState: States\.(\w+)/)[1]];
  const sequence = {};
  for (const m of text.matchAll(/state: States\.(\w+),[\s\S]*?possibleNextStates: \[([\s\S]*?)\]/g)) {
    const state = STATE[m[1]];
    if (DROPPED.has(state)) continue;
    // Upstream repeats a next state to weight it; the repeats are kept.
    sequence[state] = [...m[2].matchAll(/States\.(\w+)/g)].map((n) => STATE[n[1]]).filter((s) => !DROPPED.has(s));
  }
  const emojiBody = text.match(/get emoji\(\): string \{([\s\S]*?)\n    \}/)?.[1] ?? "";
  const emoji = strings(emojiBody).at(-1);
  const names = strings(text.match(/_NAMES: ReadonlyArray<string> = \[([\s\S]*?)\];/)[1]);
  if (!colors.length || !emoji || !names.length || !sequence[start]) throw new Error(`${file}: incomplete`);

  pets[label] = { label, emoji, speed: speedOf[cls], colors, start, sequence, names, ...OVERRIDES[label] };
}

const missing = Object.values(TYPE).filter((t) => t !== "null" && !pets[t]);
if (missing.length) throw new Error(`no pet file for: ${missing.join(", ")}`);

const out = `// Generated by scripts/gen-pets.mjs from vscode-pets ${tag}. Do not edit by hand.
// Behaviour tables and names: Copyright (c) Anthony Shaw, MIT License (see NOTICE).
export const UPSTREAM_TAG = ${JSON.stringify(tag)};

export const PETS = ${JSON.stringify(pets, null, 2)};

export const TYPES = Object.keys(PETS);
`;
const dest = join(dirname(fileURLToPath(import.meta.url)), "../mods/pets/pets.js");
writeFileSync(dest, out);
console.log(`wrote ${Object.keys(pets).length} pets to ${dest}`);
```

### Task 2: GIF size and mirror (`gif.js`)

Herdr's UI kit cannot flip an image, so a left-facing copy of every sprite has to be written as a file. This module does that with no external tool.

**Files:**
- Create: `mods/pets/gif.js`
- Create: `test/helpers.mjs`
- Test: `test/gif.test.mjs`

**Interfaces:**
- Consumes: nothing.
- Produces, from `mods/pets/gif.js`:
  - `readSize(bytes: Uint8Array): { width: number, height: number }` — throws `Error("not a GIF")`.
  - `flop(bytes: Uint8Array): Uint8Array` — the same animation mirrored left to right, straight through (tests, small files). Throws on a malformed file; it never loops on bad data.
  - `flopSteps(bytes)`: the same work as a generator that yields after every `SLICE` (16384) pixels; `flopAsync(bytes, breathe): Promise<Uint8Array>` awaits `breathe()` between steps. Herdr stops a script after about half a second without a break, so inside Herdr only `flopAsync` may be used.
  - `decode(bytes: Uint8Array): { width, height, frames: { left, top, width, height, pixels: Uint8Array }[] }` — palette indexes; for tests.
  - `lzwEncode(minCode: number, pixels: Uint8Array): Uint8Array`, `lzwDecode(minCode: number, data: Uint8Array, count: number): Uint8Array`.
- Produces, from `test/helpers.mjs`:
  - `makeGif({ width, height, palette /* 2, 4, 8 … 256 × [r,g,b] */, frames: { left?, top?, width?, height?, pixels: number[], delay?, transparent?, interlaced? }[], loop? }): Uint8Array`
  - `gifWithImageData({ width, height, minCode?, data: number[] }): Uint8Array` — one frame with the given raw image data, for malformed-data tests.
  - `controlBlocks(bytes): number[][]`
  - `seq(...values): () => number` — a random source that replays `values`, then repeats the last.

```js
// Builds small GIFs in code, so the tests ship no art.
import { lzwEncode } from "../mods/pets/gif.js";

const le16 = (v) => [v & 255, (v >> 8) & 255];

function subBlocks(data) {
  const out = [];
  for (let i = 0; i < data.length; i += 255) {
    const chunk = data.subarray(i, i + 255);
    out.push(chunk.length, ...chunk);
  }
  out.push(0);
  return out;
}

function interlace(pixels, w, h) {
  const out = new Uint8Array(pixels.length);
  let row = 0;
  for (const [start, step] of [[0, 8], [4, 8], [2, 4], [1, 2]]) {
    for (let y = start; y < h; y += step) {
      out.set(pixels.subarray(y * w, y * w + w), row * w);
      row++;
    }
  }
  return out;
}

// palette: [[r,g,b], ...] with 2, 4, 8 ... 256 entries. frames: { left, top, width, height,
// pixels (palette indexes, row by row), delay (1/100 s), transparent (index), interlaced }.
export function makeGif({ width, height, palette, frames, loop = true }) {
  const bits = Math.log2(palette.length);
  if (!Number.isInteger(bits) || bits < 1 || bits > 8) throw new Error("makeGif wants 2, 4, 8 ... 256 colours");
  const minCode = Math.max(2, bits);
  const out = [0x47, 0x49, 0x46, 0x38, 0x39, 0x61, ...le16(width), ...le16(height), 0x80 | (bits - 1), 0, 0];
  for (const [r, g, b] of palette) out.push(r, g, b);
  if (loop) out.push(0x21, 0xff, 11, ...Buffer.from("NETSCAPE2.0"), 3, 1, 0, 0, 0);
  for (const f of frames) {
    const hasAlpha = f.transparent !== undefined;
    out.push(0x21, 0xf9, 4, (2 << 2) | (hasAlpha ? 1 : 0), ...le16(f.delay ?? 12), hasAlpha ? f.transparent : 0, 0);
    const fw = f.width ?? width;
    const fh = f.height ?? height;
    out.push(0x2c, ...le16(f.left ?? 0), ...le16(f.top ?? 0), ...le16(fw), ...le16(fh), f.interlaced ? 0x40 : 0);
    const px = Uint8Array.from(f.pixels);
    out.push(minCode, ...subBlocks(lzwEncode(minCode, f.interlaced ? interlace(px, fw, fh) : px)));
  }
  out.push(0x3b);
  return Uint8Array.from(out);
}

// A one-frame GIF whose image data is the given raw bytes, for malformed-data tests.

// Every Graphic Control Extension's bytes, in order: delays, disposal, transparency.

  const found = [];

    if (bytes[i] === 0x21 && bytes[i + 1] === 0xf9 && bytes[i + 2] === 4 && bytes[i + 7] === 0) {
      found.push([...bytes.subarray(i + 3, i + 7)]);
    }
  }
  return found;
}

// A random source that replays the given numbers, then repeats the last one.

  let i = 0;
  return () => values[Math.min(i++, values.length - 1)];
```

```js
// Reads a GIF's size and writes a mirrored copy. Pure: bytes in, bytes out.
// Herdr's UI kit cannot flip an image, so left-facing sprites have to exist as files.
//
// Herdr stops a script that runs for about half a second without a break, and the
// stop cannot be caught. A big sprite (totoro's is 27 frames of 600 x 396) takes
// longer than that to mirror. So the work is written as steps: every function with a
// * yields after each SLICE pixels, flop() runs the steps straight through, and
// flopAsync() takes a breath between them.

const u16 = (b, p) => b[p] | (b[p + 1] << 8);
const tableLength = (packed) => (packed & 0x80 ? 3 * (1 << ((packed & 7) + 1)) : 0);
// Far beyond any sprite (the largest upstream one is 696 x 460). A frame claiming
// more is not decoded.
const MAX_PIXELS = 4_000_000;
// Pixels of work between two breaths: a few milliseconds in Herdr's script engine.
export const SLICE = 16384;

export function readSize(bytes) {
  if (bytes.length < 13 || bytes[0] !== 0x47 || bytes[1] !== 0x49 || bytes[2] !== 0x46) throw new Error("not a GIF");
  return { width: u16(bytes, 6), height: u16(bytes, 8) };
}

// Runs a stepped function to its end without a break.
function finish(steps) {
  for (;;) {
    const r = steps.next();
    if (r.done) return r.value;
  }
}

// GIF data is cut into sub-blocks: a length byte, that many bytes, ... and a 0 to end.
function readSubBlocks(b, p) {
  const parts = [];
  let total = 0;
  while (p < b.length && b[p] !== 0) {
    parts.push(b.subarray(p + 1, p + 1 + b[p]));
    total += b[p];
    p += b[p] + 1;
  }
  if (p >= b.length) throw new Error("GIF data runs past the end of the file");
  const data = new Uint8Array(total);
  let at = 0;
  for (const part of parts) { data.set(part, at); at += part.length; }
  return { data, end: p + 1 };
}

function subBlocks(data) {
  const out = new Uint8Array(data.length + Math.ceil(data.length / 255) + 1);
  let o = 0;
  for (let i = 0; i < data.length; i += 255) {
    const n = Math.min(255, data.length - i);
    out[o++] = n;
    out.set(data.subarray(i, i + n), o);
    o += n;
  }
  out[o++] = 0;
  return out.subarray(0, o);
}

function* lzwDecodeSteps(minCode, data, count) {
  const clear = 1 << minCode;
  const eoi = clear + 1;
  const prefix = new Uint16Array(4096);
  const suffix = new Uint8Array(4096);
  const stack = new Uint8Array(4097);
  const out = new Uint8Array(count);
  for (let i = 0; i < clear; i++) suffix[i] = i;
  let size = minCode + 1;
  let mask = (1 << size) - 1;
  let avail = clear + 2;
  let old = -1;
  let first = 0;
  let datum = 0;
  let bits = 0;
  let op = 0;
  let breath = SLICE;
  for (let p = 0; p < data.length; p++) {
    datum |= data[p] << bits;
    bits += 8;
    while (bits >= size) {
      let code = datum & mask;
      datum >>= size;
      bits -= size;
      if (code === clear) {
        size = minCode + 1;
        mask = (1 << size) - 1;
        avail = clear + 2;
        old = -1;
        continue;
      }
      if (code === eoi) {
        if (op < count) throw new Error("GIF image data ends early");
        return out;
      }
      // A code may name a colour, an entry already made, or the one being made now.
      // Anything else is corrupt, and following it would never end.
      if (code > avail || (old === -1 && code >= clear)) throw new Error("bad GIF image data");
      if (old === -1) {
        if (op < count) out[op++] = suffix[code];
        old = code;
        first = code;
        continue;
      }
      const incoming = code;
      let sp = 0;
      if (code >= avail) {
        stack[sp++] = first;
        code = old;
      }
      while (code >= clear) {
        stack[sp++] = suffix[code];
        code = prefix[code];
      }
      first = suffix[code];
      stack[sp++] = first;
      if (avail < 4096) {
        prefix[avail] = old;
        suffix[avail] = first;
        avail++;
        if ((avail & mask) === 0 && avail < 4096) {
          size++;
          mask = (1 << size) - 1;
        }
      }
      old = incoming;
      while (sp > 0 && op < count) out[op++] = stack[--sp];
    }
    if (op >= breath) {
      breath = op + SLICE;
      yield;
    }
  }
  if (op < count) throw new Error("GIF image data ends early");
  return out;
}

// The writer's table of (code so far, next pixel) -> code, as two flat arrays:
// much quicker in Herdr's script engine than a Map.
const SLOTS = 8192; // a power of two, twice the 4096 codes there can be
function* lzwEncodeSteps(minCode, pixels) {
  const clear = 1 << minCode;
  const eoi = clear + 1;
  // A code is at most 12 bits and there is at most one per pixel, plus the two ends.
  const out = new Uint8Array(pixels.length * 2 + 16);
  const keys = new Int32Array(SLOTS).fill(-1);
  const codes = new Uint16Array(SLOTS);
  let o = 0;
  let size = minCode + 1;
  let next = eoi + 1;
  let datum = 0;
  let bits = 0;
  const emit = (code) => {
    datum |= code << bits;
    bits += size;
    while (bits >= 8) {
      out[o++] = datum & 255;
      datum >>>= 8;
      bits -= 8;
    }
  };
  emit(clear);
  if (pixels.length > 0) {
    let cur = pixels[0];
    for (let i = 1; i < pixels.length; i++) {
      const px = pixels[i];
      const key = (cur << 8) | px;
      let slot = (Math.imul(key, 0x9e3779b1) >>> 19) & (SLOTS - 1);
      while (keys[slot] !== -1 && keys[slot] !== key) slot = (slot + 1) & (SLOTS - 1);
      if (keys[slot] === key) {
        cur = codes[slot];
      } else {
        emit(cur);
        if (next < 4096) {
          keys[slot] = key;
          codes[slot] = next++;
          // The reader grows its code size one code later than the writer adds an entry.
          if (next > 1 << size && size < 12) size++;
        } else {
          emit(clear);
          keys.fill(-1);
          size = minCode + 1;
          next = eoi + 1;
        }
        cur = px;
      }
      if (i % SLICE === 0) yield;
    }
    emit(cur);
  }
  emit(eoi);
  if (bits > 0) out[o++] = datum & 255;
  return out.subarray(0, o);
}

export const lzwDecode = (minCode, data, count) => finish(lzwDecodeSteps(minCode, data, count));
export const lzwEncode = (minCode, pixels) => finish(lzwEncodeSteps(minCode, pixels));

// Interlaced frames store rows 0,8,16.. then 4,12.. then 2,6,10.. then 1,3,5..
function deinterlace(px, w, h) {
  const out = new Uint8Array(px.length);
  let row = 0;
  for (const [start, step] of [[0, 8], [4, 8], [2, 4], [1, 2]]) {
    for (let y = start; y < h; y += step) {
      out.set(px.subarray(row * w, row * w + w), y * w);
      row++;
    }
  }
  return out;
}

// Walks the file: { width, height, headEnd, blocks }, each block either
// { ext: [start, end] } (copied through as is) or a decoded image.
function* parseSteps(bytes) {
  const { width, height } = readSize(bytes);
  let p = 13 + tableLength(bytes[10]);
  const headEnd = p;
  const blocks = [];
  for (;;) {
    if (p >= bytes.length) throw new Error("GIF ended without a trailer");
    const kind = bytes[p];
    if (kind === 0x3b) break;
    if (kind === 0x21) {
      let q = p + 2;
      while (q < bytes.length && bytes[q] !== 0) q += bytes[q] + 1;
      if (q >= bytes.length) throw new Error("GIF extension runs past the end of the file");
      blocks.push({ ext: [p, q + 1] });
      p = q + 1;
      continue;
    }
    if (kind !== 0x2c) throw new Error(`unknown GIF block 0x${kind.toString(16)} at byte ${p}`);
    if (p + 11 > bytes.length) throw new Error("GIF ended inside an image header");
    const left = u16(bytes, p + 1);
    const top = u16(bytes, p + 3);
    const w = u16(bytes, p + 5);
    const h = u16(bytes, p + 7);
    const packed = bytes[p + 9];
    if (w * h > MAX_PIXELS) throw new Error("GIF frame is too large");
    const table = [p + 10, p + 10 + tableLength(packed)];
    const minCode = bytes[table[1]];
    if (!(minCode >= 2 && minCode <= 8)) throw new Error(`bad GIF code size ${minCode}`);
    const { data, end } = readSubBlocks(bytes, table[1] + 1);
    let pixels = yield* lzwDecodeSteps(minCode, data, w * h);
    if (packed & 0x40) pixels = deinterlace(pixels, w, h);
    blocks.push({ left, top, width: w, height: h, packed, table, minCode, pixels });
    p = end;
    yield;
  }
  return { width, height, headEnd, blocks };
}

// The frames as palette indexes, for tests and debugging.
export function decode(bytes) {
  const g = finish(parseSteps(bytes));
  return {
    width: g.width,
    height: g.height,
    frames: g.blocks.filter((b) => !b.ext).map(({ left, top, width, height, pixels }) => ({ left, top, width, height, pixels })),
  };
}

// The same animation, mirrored left to right, as steps. Colours, delays, disposal,
// transparency and looping are copied through untouched.
export function* flopSteps(bytes) {
  const g = yield* parseSteps(bytes);
  const parts = [bytes.subarray(0, g.headEnd)];
  for (const b of g.blocks) {
    if (b.ext) {
      parts.push(bytes.subarray(b.ext[0], b.ext[1]));
      continue;
    }
    const { width: w, height: h, pixels } = b;
    for (let y = 0; y < h; y++) pixels.subarray(y * w, y * w + w).reverse();
    const left = Math.max(0, g.width - b.left - w);
    parts.push(Uint8Array.from([
      0x2c, left & 255, left >> 8, b.top & 255, b.top >> 8, w & 255, w >> 8, h & 255, h >> 8,
      b.packed & ~0x40, // rows are written in order now
    ]));
    parts.push(bytes.subarray(b.table[0], b.table[1]));
    parts.push(Uint8Array.from([b.minCode]));
    parts.push(subBlocks(yield* lzwEncodeSteps(b.minCode, pixels)));
    yield;
  }
  parts.push(Uint8Array.from([0x3b]));
  const out = new Uint8Array(parts.reduce((n, part) => n + part.length, 0));
  let at = 0;
  for (const part of parts) { out.set(part, at); at += part.length; }
  return out;
}

// For small files and for tests: straight through, no breaks.
export const flop = (bytes) => finish(flopSteps(bytes));

// For use inside Herdr: `breathe` is awaited between slices. It must hand control
// back to the app (any real asynchronous call does), or a big sprite is cut off.
export async function flopAsync(bytes, breathe) {
  const steps = flopSteps(bytes);
  for (;;) {
    const r = steps.next();
    if (r.done) return r.value;
    await breathe();
  }
}
```

```js
// Pet behaviour. vscode-pets moves every pet a few pixels each 100 ms; here a state
// becomes one leg (where to, how long) that Herdr animates natively, and the engine
// is only asked again when the leg is over. Pure: no Herdr, the clock and the random
// source are arguments.
//
// Coordinates: x is the sprite's left edge, y its bottom edge above the panel's bottom.
// env: { width, height, floor } in the same pixels. A pet carries its drawn size (w, h).
import { PETS } from "./pets.js";

export const TICK = 100; // upstream's frame, ms; hold times below are in ticks
export const SIZES = { nano: 30, small: 40, medium: 55, large: 110 };

// How each upstream state plays. face null: keep the way the pet faces.
// air: off the ground (upstream's isStateAboveGround).
export const STATES = {
  "sit-idle": { sprite: "idle", face: "right", hold: 50 },
  lie: { sprite: "lie", face: "right", hold: 50 },
  "stand-right": { sprite: "stand", face: "right", hold: 60 },
  "stand-left": { sprite: "stand", face: "left", hold: 60 },
  swipe: { sprite: "swipe", face: null, hold: 15 },
  "walk-right": { sprite: "walk", face: "right", move: "right", factor: 1, hold: 60 },
  "walk-left": { sprite: "walk", face: "left", move: "left", factor: 1, hold: 60 },
  "run-right": { sprite: "walk_fast", face: "right", move: "right", factor: 1.6, hold: 130 },
  "run-left": { sprite: "walk_fast", face: "left", move: "left", factor: 1.6, hold: 130 },
  "climb-wall-left": { sprite: "wallclimb", face: "left", move: "up", air: true },
  "wall-hang-left": { sprite: "wallgrab", face: "left", hold: 50, air: true },
  "wall-dig-left": { sprite: "walldig", face: "left", hold: 60, air: true },
  "wall-nap": { sprite: "wallnap", face: "right", hold: 50, air: true },
  "jump-down-left": { sprite: "fall_from_grab", face: "right", move: "down", air: true },
  land: { sprite: "land", face: "left", hold: 10, air: true },
};

const CLIMB_SPEED = 1; // px per tick, unless the pet says otherwise
const FALL_SPEED = 5;
const CLIMB_HEIGHT = 100;

// The sprite files a pet type needs: one per state it can be in, plus the hover reaction.
export function spritesFor(type) {
  const out = new Set(["swipe"]);
  for (const state of Object.keys(PETS[type].sequence)) out.add(STATES[state].sprite);
  return [...out];
}

const rightEdge = (pet, env) => Math.max(0, Math.floor(env.width * 0.95) - pet.w);
const travel = (px, pxPerSec) => Math.max(TICK, Math.round((px / pxPerSec) * 1000));

// How high this pet climbs to, as [lowest, highest], or null when the panel is too short.
function climbRange(def, pet, env) {
  if (def.climbRange) {
    const lo = Math.max(pet.h * 2, env.height * def.climbRange[0]);
    const hi = Math.min(env.height - pet.h, env.height * def.climbRange[1]);
    return hi >= lo ? [lo, hi] : null;
  }
  return env.height >= CLIMB_HEIGHT + pet.h ? [CLIMB_HEIGHT, CLIMB_HEIGHT] : null;
}

// Puts the pet in `state` at `pos` and returns the leg that plays it.
export function enter(pet, state, pos, env, now, rng) {
  const def = PETS[pet.type];
  const s = STATES[state];
  const y = s.air ? pos.y : env.floor;
  const leg = {
    state,
    sprite: s.sprite,
    face: s.face ?? pet.face,
    fromX: pos.x, toX: pos.x,
    fromY: y, toY: y,
    start: now,
    duration: (s.hold ?? 0) * TICK,
    bubble: null,
  };
  const speed = pet.pxPerSec * (s.factor ?? 1);
  if ((s.move === "right" || s.move === "left") && speed > 0) {
    leg.toX = s.move === "right" ? rightEdge(pet, env) : 0;
    leg.duration = travel(Math.abs(leg.toX - leg.fromX), speed);
  } else if (s.move === "up") {
    const [lo, hi] = climbRange(def, pet, env) ?? [y, y];
    // On a high floor (castle or beach at large is 120) the pet already stands above
    // the climb height; upstream ends the climb at once, and so does this.
    leg.toY = Math.max(y, Math.round(lo + rng() * (hi - lo)));
    leg.duration = travel(Math.abs(leg.toY - y), (def.climbSpeed ?? CLIMB_SPEED) * 10);
  } else if (s.move === "down") {
    leg.toY = env.floor;
    leg.duration = travel(Math.abs(y - env.floor), (def.fallSpeed ?? FALL_SPEED) * 10);
  }
  pet.state = state;
  pet.face = leg.face;
  pet.leg = leg;
  return leg;
}

// A new pet from a saved one ({ id, type, color, name }), somewhere on the ground.
export function spawn(saved, box, env, now, rng) {
  const def = PETS[saved.type];
  const pet = {
    id: saved.id, type: saved.type, color: saved.color, name: saved.name,
    w: box, h: box,
    // Upstream: speed px per tick, 0.7x to 1.3x per pet. Ten ticks a second.
    pxPerSec: def.speed * (def.speedFactor ?? 1) * (0.7 + rng() * 0.6) * 10,
    face: "right",
    state: def.start,
    held: null, // the state a hover interrupted
    leg: null,
  };
  const x = Math.min(Math.floor(rng() * env.width * 0.7), rightEdge(pet, env));
  enter(pet, def.start, { x, y: env.floor }, env, now, rng);
  return pet;
}

// Where the pet is now, part-way through its leg.
export function positionAt(leg, now) {
  const f = leg.duration > 0 ? Math.min(1, Math.max(0, (now - leg.start) / leg.duration)) : 1;
  return { x: leg.fromX + (leg.toX - leg.fromX) * f, y: leg.fromY + (leg.toY - leg.fromY) * f };
}

function nextState(pet, env, rng) {
  const def = PETS[pet.type];
  let options = def.sequence[pet.state] ?? [def.start];
  if (!climbRange(def, pet, env)) options = options.filter((s) => s !== "climb-wall-left");
  if (options.length === 0) return def.start;
  return options[Math.min(options.length - 1, Math.floor(rng() * options.length))];
}

// Call often. True when the leg had ended and the pet started a new one.
export function step(pet, env, now, rng) {
  if (now < pet.leg.start + pet.leg.duration) return false;
  const pos = { x: pet.leg.toX, y: pet.leg.toY };
  const state = pet.held ?? nextState(pet, env, rng);
  pet.held = null;
  enter(pet, state, pos, env, now, rng);
  return true;
}

function bubbleFor(pet, rng) {
  const def = PETS[pet.type];
  if (def.bubbles) return def.bubbles[Math.min(def.bubbles.length - 1, Math.floor(rng() * def.bubbles.length))];
  return def.bubbleByColor?.[pet.color] ?? def.bubble ?? "👋";
}

// The pointer came over the pet: it stops where it is, reacts, then carries on.
// False when it can't (already reacting, or off the ground).
export function swipe(pet, env, now, rng) {
  if (pet.state === "swipe" || STATES[pet.state].air) return false;
  const pos = positionAt(pet.leg, now);
  pet.held = pet.state;
  enter(pet, "swipe", pos, env, now, rng).bubble = bubbleFor(pet, rng);
  return true;
}

// The panel, the sprite size or the theme changed. Replans a leg that no longer fits;
// true when it did. A pet on the wall that is now out of bounds comes down.
export function refit(pet, env, now, rng) {
  const def = PETS[pet.type];
  const edge = rightEdge(pet, env);
  const pos = positionAt(pet.leg, now);
  // "land" counts as off the ground upstream, but the pet is standing on it.
  const grounded = !STATES[pet.state].air || pet.state === "land";
  const top = Math.max(env.floor, env.height - pet.h); // as high as its feet can be
  const inside = (y) => y >= env.floor && y <= top;
  const fitsX = pet.leg.toX <= edge && pos.x <= edge;
  const fitsY = grounded
    ? pet.leg.fromY === env.floor && pet.leg.toY === env.floor
    : inside(pos.y) && inside(pet.leg.toY);
  if (fitsX && fitsY) return false;
  const x = Math.min(pos.x, edge);
  if (grounded) {
    const bubble = pet.leg.bubble;
    enter(pet, pet.state, { x, y: env.floor }, env, now, rng).bubble = bubble;
  } else if (def.sequence["jump-down-left"]) {
    enter(pet, "jump-down-left", { x, y: Math.min(Math.max(pos.y, env.floor), top) }, env, now, rng);
  } else {
    enter(pet, def.start, { x, y: env.floor }, env, now, rng);
  }
  return true;
}
```

```js
// What is saved: the pets, the size and the theme. Pure helpers over that one value;
// main.js reads it with shared(KEY) and writes it with setShared(KEY, value).
import { PETS } from "./pets.js";

export const KEY = "pets";
export const MAX_PETS = 20;
export const SIZE_NAMES = ["nano", "small", "medium", "large"];
export const THEMES = ["none", "forest", "castle", "beach", "winter", "autumn", "library"];
// Upstream starts at nano (30 px), sized for a wide editor panel. In a Herdr sidebar
// that is too small to see, so this starts one step below upstream's largest.
export const DEFAULT_SIZE = "medium";

// Where the ground is in each theme's picture, px above the bottom (upstream themes.ts).
const FLOORS = {
  none: { nano: 0, small: 0, medium: 0, large: 0 },
  forest: { nano: 23, small: 30, medium: 40, large: 65 },
  castle: { nano: 45, small: 60, medium: 80, large: 120 },
  beach: { nano: 45, small: 60, medium: 80, large: 120 },
  winter: { nano: 18, small: 20, medium: 30, large: 45 },
  autumn: { nano: 7, small: 9, medium: 15, large: 20 },
  library: { nano: 16, small: 22, medium: 32, large: 44 },
};

export const floorFor = (theme, size) => FLOORS[theme]?.[size] ?? 0;

const pick = (list, rng) => list[Math.min(list.length - 1, Math.floor(rng() * list.length))];

export const randomName = (type, rng) => pick(PETS[type].names, rng);

export const newId = (now, rng) => `${now.toString(36)}-${Math.floor(rng() * 1e9).toString(36)}`;

// Whatever was saved, as a value the rest of the mod can trust.
export function load(raw) {
  const saved = raw && typeof raw === "object" ? raw : {};
  const pets = [];
  const ids = new Set();
  for (const p of Array.isArray(saved.pets) ? saved.pets : []) {
    if (pets.length >= MAX_PETS) break;
    if (!p || typeof p !== "object" || typeof p.id !== "string" || ids.has(p.id)) continue;
    // A type must be a string naming one of PETS' own entries: not an array that
    // reads as "dog", and not "constructor", which every object has.
    const def = typeof p.type === "string" && Object.hasOwn(PETS, p.type) ? PETS[p.type] : null;
    if (!def) continue; // a pet type this version no longer has
    ids.add(p.id);
    pets.push({
      id: p.id,
      type: p.type,
      color: def.colors.includes(p.color) ? p.color : def.colors[0],
      name: typeof p.name === "string" && p.name.trim() ? p.name.trim() : def.names[0],
    });
  }
  return {
    pets,
    size: SIZE_NAMES.includes(saved.size) ? saved.size : DEFAULT_SIZE,
    theme: THEMES.includes(saved.theme) ? saved.theme : "none",
  };
}

// Each returns a new saved value; the one passed in is left alone.
export function addPet(state, pet) {
  if (state.pets.length >= MAX_PETS) return state;
  return load({ ...state, pets: [...state.pets, pet] });
}

export const removePet = (state, id) => ({ ...state, pets: state.pets.filter((p) => p.id !== id) });

export function renamePet(state, id, name) {
  const clean = String(name ?? "").trim();
  if (!clean) return state;
  return { ...state, pets: state.pets.map((p) => (p.id === id ? { ...p, name: clean } : p)) };
}

export const removeAll = (state) => ({ ...state, pets: [] });
export const withSize = (state, size) => (SIZE_NAMES.includes(size) ? { ...state, size } : state);
export const withTheme = (state, theme) => (THEMES.includes(theme) ? { ...state, theme } : state);

// What a key command does to the saved value: "size-<name>", "theme-<name>" or
// "remove-all" ("pets.size-large" in keys.json). Null for any other command.
export function applyCommand(state, command) {
  const c = String(command ?? "");
  if (c === "remove-all") return removeAll(state);
  for (const [prefix, change] of [["size-", withSize], ["theme-", withTheme]]) {
    if (!c.startsWith(prefix)) continue;
    const next = change(state, c.slice(prefix.length));
    return next === state ? null : next;
  }
  return null;
}
```

```js
// Where sprite files are and what they are called. Pure: names and numbers only.

// Editors' extension folders, under the home directory.
export const EDITOR_DIRS = [".vscode/extensions", ".vscode-insiders/extensions", ".cursor/extensions", ".vscode-oss/extensions"];

const PREFIX = "tonybaloney.vscode-pets-";

// Pets whose art is not in the upstream GitHub repo: they need the installed extension.
export const EXTENSION_ONLY = ["cat", "frog", "bunny", "squirrel"];

// Of a folder's entries, the newest vscode-pets one ("tonybaloney.vscode-pets-1.37.0"), or null.
export function newestExtension(names) {
  const version = (n) => n.slice(PREFIX.length).split(/[.-]/).map((x) => Number.parseInt(x, 10) || 0);
  const found = names.filter((n) => n.startsWith(PREFIX));
  found.sort((a, b) => {
    const [x, y] = [version(a), version(b)];
    for (let i = 0; i < Math.max(x.length, y.length); i++) {
      if ((x[i] ?? 0) !== (y[i] ?? 0)) return (x[i] ?? 0) - (y[i] ?? 0);
    }
    return 0;
  });
  return found.at(-1) ?? null;
}

// Upstream's file name for one animation. Colours with a space use an underscore on disk.
export const spriteName = (color, label) => `${color.replaceAll(" ", "_")}_${label}_8fps.gif`;

// The mirrored copy this mod writes next to it.
export const leftName = (name) => name.replace(/\.gif$/, ".left.gif");

export const rawUrl = (tag, rel) => `https://raw.githubusercontent.com/tonybaloney/vscode-pets/${tag}/media/${rel.split("/").map(encodeURIComponent).join("/")}`;

// A theme's two pictures for this size and appearance, relative to media/.
export function themeFiles(theme, dark, size) {
  const kind = dark ? "dark" : "light";
  return {
    background: `backgrounds/${theme}/background-${kind}-${size}.png`,
    foreground: `backgrounds/${theme}/foreground-${kind}-${size}.png`,
  };
}

// The size a sprite is drawn at: inside a box, never enlarged (upstream's max-width/max-height),
// and never thinner than a pixel.
export function fit(width, height, box) {
  const k = Math.min(1, box / width, box / height);
  return { w: Math.max(1, Math.round(width * k)), h: Math.max(1, Math.round(height * k)) };
}

export function pngSize(bytes) {
  const sig = [0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a];
  if (bytes.length < 24 || sig.some((v, i) => bytes[i] !== v)) throw new Error("not a PNG");
  const be32 = (p) => ((bytes[p] << 24) | (bytes[p + 1] << 16) | (bytes[p + 2] << 8) | bytes[p + 3]) >>> 0;
  const size = { width: be32(16), height: be32(20) };
  // A picture is tiled across the panel by its width, so a size of 0 must never get out.
  if (size.width === 0 || size.height === 0) throw new Error("not a PNG");
  return size;
}
```

```js
// Finds the sprites and keeps a copy under ~/.config/herdr-app/data/pets/.
// The logic lives here with its file and program access passed in, so it runs under
// tests; art.js hands it Herdr's real ones. Nothing it fetches is ever part of this repo.
//
// Every copy of the mod shares this module, and Herdr stops a closed dialog's work
// part-way. So no call waits on another's: each does its own work, downloads into a
// file of its own, and puts only finished files in place. Two calls for the same pet
// write the same bytes to the same names.
import { UPSTREAM_TAG } from "./pets.js";
import { spritesFor } from "./engine.js";
import { readSize, flopAsync } from "./gif.js";
import { EDITOR_DIRS, EXTENSION_ONLY, newestExtension, spriteName, leftName, rawUrl, themeFiles, pngSize } from "./sources.js";

export const DATA_REL = "data/pets"; // image() paths are relative to ~/.config/herdr-app
const RECIPE = 1; // bump when what is cached changes shape, so old caches are rebuilt
const CURL_SECONDS = 20; // per attempt
const EXEC_MS = 90000; // curl's three attempts and their pauses fit inside this
const MAX_BYTES = 20_000_000; // no sprite or picture comes near this
const RECHECK_MS = 30000; // how long "no extension installed" is believed
// Herdr stops a script that runs about half a second without a break, and the stop
// cannot be caught. Mirroring pauses at least this often, far inside that limit.
const BREATH_MS = 25;

const dirOf = (path) => path.slice(0, path.lastIndexOf("/"));
const reason = (e) => String(e?.message ?? e);

// io: { exec, fs, home, appHome } with the shapes of Herdr's `exec`, `fs/promises`,
// `home()` and `appHome()`. `pause` resolves after handing control back to the app
// (any real asynchronous call does); `now` is the clock, for tests.
export function createArt({ exec, fs, home, appHome, pause = async () => {}, now = Date.now }) {
  const has = (path) => fs.exists(path).catch(() => false);
  const remove = (path) => fs.unlink(path).catch(() => {});
  let downloads = 0;

  // Awaited between slices of mirroring: a real pause once BREATH_MS has gone by.
  let breathed = now();
  async function breathe() {
    const since = now() - breathed;
    if (since >= 0 && since < BREATH_MS) return; // a clock set back still gets its pause
    await pause();
    breathed = now();
  }

  // The media folder of the newest installed vscode-pets, or null. Once found it is
  // remembered; "none" is looked up again after a while, so installing the extension
  // is noticed without restarting Herdr.
  let known = null; // { media, at }
  async function extensionMedia() {
    if (known && (known.media || now() - known.at < RECHECK_MS)) return known.media;
    const media = await findExtension();
    known = { media, at: now() };
    return media;
  }

  async function findExtension() {
    const found = new Map(); // extension folder name -> its media folder
    for (const rel of EDITOR_DIRS) {
      const dir = `${home()}/${rel}`;
      const name = newestExtension(await fs.readdir(dir).catch(() => []));
      if (name && !found.has(name) && (await has(`${dir}/${name}/media`))) found.set(name, `${dir}/${name}/media`);
    }
    const newest = newestExtension([...found.keys()]);
    return newest ? found.get(newest) : null;
  }

  // Puts media/<rel> at dest and returns its bytes; null when upstream has no such file.
  async function obtain(rel, dest) {
    const dir = await extensionMedia();
    if (dir && (await has(`${dir}/${rel}`))) {
      const bytes = await fs.readFile(`${dir}/${rel}`);
      await fs.writeFile(dest, bytes);
      return bytes;
    }
    // curl writes to a side file that only this call uses, so a download that is cut
    // short, or another call's download, never sits at dest.
    const part = `${dest}.${now().toString(36)}-${(downloads++).toString(36)}.part`;
    let r;
    try {
      r = await exec(
        "curl",
        [
          "-sL", "--proto", "=https", "--retry", "2", "--connect-timeout", "10",
          "--max-time", String(CURL_SECONDS), "--max-filesize", String(MAX_BYTES),
          "-o", part, "-w", "%{http_code}", rawUrl(UPSTREAM_TAG, rel),
        ],
        { timeout: EXEC_MS },
      );
    } catch (e) {
      await remove(part);
      throw new Error(`Sprites need either vscode-pets installed in an editor, or curl (${reason(e)}).`);
    }
    const status = r.stdout.trim();
    if (r.code !== 0 || status !== "200") {
      await remove(part);
      if (r.code === 0 && status === "404") return null; // upstream has no such file
      throw new Error(r.code !== 0 ? `Download failed (curl ${r.code}). Check the connection.` : `Download failed (HTTP ${status}).`);
    }
    try {
      const bytes = await fs.readFile(part);
      await fs.writeFile(dest, bytes);
      return bytes;
    } finally {
      await remove(part);
    }
  }

  // The cached answer for one pet, or null when any of it is missing or out of date.
  async function cachedPet(metaFile) {
    try {
      const meta = JSON.parse(await fs.readFile(metaFile, "utf8"));
      const sprites = Object.values(meta.sprites ?? {});
      if (meta.recipe !== RECIPE || sprites.length === 0) return null;
      for (const s of sprites) {
        if (!(s.width > 0 && s.height > 0)) return null;
        if (!(await has(`${appHome()}/${s.right}`)) || !(await has(`${appHome()}/${s.left}`))) return null;
      }
      return meta;
    } catch {
      return null;
    }
  }

  // One pet's animations: { recipe, sprites: { <label>: { right, left, width, height } } },
  // with paths ready for image(). Cached per type and colour.
  async function loadPet(type, color) {
    const dir = `${appHome()}/${DATA_REL}/${type}`;
    const metaFile = `${dir}/${color.replaceAll(" ", "_")}.json`;
    const cached = await cachedPet(metaFile);
    if (cached) return cached;
    if (EXTENSION_ONLY.includes(type) && !(await extensionMedia())) {
      throw new Error("Needs the vscode-pets extension installed in an editor.");
    }
    await fs.mkdir(dir, { recursive: true });
    const sprites = {};
    for (const label of spritesFor(type)) {
      const name = spriteName(color, label);
      const bytes = await obtain(`${type}/${name}`, `${dir}/${name}`);
      if (!bytes) continue;
      let size;
      try {
        size = readSize(bytes);
      } catch {
        await remove(`${dir}/${name}`);
        throw new Error(`The ${color} ${type}'s "${label}" sprite is not a valid GIF.`);
      }
      let left = name;
      try {
        await fs.writeFile(`${dir}/${leftName(name)}`, await flopAsync(bytes, breathe));
        left = leftName(name);
      } catch (e) {
        // One odd file shouldn't cost the pet: it walks backwards in this state.
        console.log(`pets: could not mirror ${type}/${name}: ${reason(e)}`);
      }
      sprites[label] = { right: `${DATA_REL}/${type}/${name}`, left: `${DATA_REL}/${type}/${left}`, width: size.width, height: size.height };
    }
    if (Object.keys(sprites).length === 0) throw new Error(`No sprites found for the ${color} ${type}.`);
    const meta = { recipe: RECIPE, sprites };
    await fs.writeFile(metaFile, JSON.stringify(meta));
    return meta;
  }

  // A theme's pictures: { background, foreground }, each { path, width, height } or null.
  async function loadTheme(theme, dark, size) {
    const out = {};
    for (const [layer, rel] of Object.entries(themeFiles(theme, dark, size))) {
      const dest = `${appHome()}/${DATA_REL}/${rel}`;
      let bytes;
      if (await has(dest)) {
        bytes = await fs.readFile(dest);
      } else {
        await fs.mkdir(dirOf(dest), { recursive: true });
        bytes = await obtain(rel, dest);
      }
      if (!bytes) {
        out[layer] = null;
        continue;
      }
      try {
        out[layer] = { path: `${DATA_REL}/${rel}`, ...pngSize(bytes) };
      } catch {
        await remove(dest); // not kept, so the next try fetches it again
        throw new Error(`The ${theme} theme's ${layer} picture is not a valid PNG.`);
      }
    }
    if (!out.background && !out.foreground) throw new Error(`No pictures found for the ${theme} theme.`);
    return out;
  }

  return { extensionMedia, loadPet, loadTheme };
}
```

Facts this relies on, all from `~/.config/herdr-app/gpui-kit.d.ts` and `herdr.d.ts`:
- A mod's `fetch` response has only `text()` and `json()`, so binary downloads go through `exec("curl", …)`.
- `exec`'s `timeout` is in milliseconds and defaults to 30,000; it rejects on timeout or when the program cannot start.
- curl is run without `-f` and with `-w "%{http_code}"`, so the status tells a missing animation (404) apart from a server error.
- `fs/promises` has `unlink` but no `rename`, so a download goes to a side file that only that call uses; it is read back, written to its place and removed.
- Every copy of the mod shares this module, and Herdr stops a closed dialog's work part-way, leaving its promise pending for ever. So no load waits on another's promise.
- `fs/promises` `readFile(path)` resolves a `Uint8Array`; `writeFile` accepts one.

```js
// Keeps the pets on screen in step with the saved list, and says what to draw for
// each. Pure: main.js calls this from its timer and its render.
import { spawn, step, swipe, refit } from "./engine.js";
import { fit } from "./sources.js";

// The size the engine reckons with for a pet: its idle sprite's, drawn in the box.
// Without sprites it is the box itself.
export function referenceSize(sprites, box) {
  const ref = sprites && (sprites.idle ?? sprites.walk ?? Object.values(sprites)[0]);
  return ref ? fit(ref.width, ref.height, box) : { w: box, h: box };
}

// Brings `live` (pet id -> the engine's pet, changed in place) up to date.
//   saved:     [{ id, type, color, name }], from the store
//   spritesOf: (saved pet) -> its loaded sprites, or null while there are none
// True when something changed that needs a redraw.
export function reconcile(live, saved, spritesOf, box, env, now, rng) {
  let changed = false;
  const ids = new Set();
  for (const p of saved) {
    ids.add(p.id);
    let pet = live[p.id];
    if (!pet) {
      pet = live[p.id] = spawn(p, box, env, now, rng);
      changed = true;
    }
    pet.name = p.name;
    const sprites = spritesOf(p);
    const size = referenceSize(sprites, box);
    pet.w = size.w;
    pet.h = size.h;
    if (refit(pet, env, now, rng)) changed = true;
    // No sprites yet, or none to be had: it waits where it is, as its emoji.
    if (sprites && step(pet, env, now, rng)) changed = true;
  }
  for (const id of Object.keys(live)) {
    if (!ids.has(id)) {
      delete live[id];
      changed = true;
    }
  }
  return changed;
}

// The pointer came over a pet. Only a pet that has sprites reacts; true when it did.
export function hover(pet, sprites, env, now, rng) {
  return !!sprites && swipe(pet, env, now, rng);
}

// What to draw for a pet now.
//   x, y:      where its box ends up: left edge, and bottom edge above the panel's bottom
//   moveX/Y:   ms left of the glide on that axis, or 0 when it does not move on it
//   sprite:    { path, w, h }, to stand on the bottom of the box; null: draw the emoji
//   w, h:      the size to give the element when there is no sprite
//   bubble:    text to show above it, or null
// A sprite's animations differ in height, so the caller must keep the box a fixed
// height and stand the picture on its bottom: then `y` never depends on the sprite.
export function drawing(pet, sprites, box, now) {
  const leg = pet.leg;
  const left = Math.max(1, Math.round(leg.start + leg.duration - now));
  const s = sprites && (sprites[leg.sprite] ?? sprites.idle ?? sprites.walk ?? Object.values(sprites)[0]);
  return {
    x: leg.toX,
    y: leg.toY,
    moveX: leg.toX !== leg.fromX ? left : 0,
    moveY: leg.toY !== leg.fromY ? left : 0,
    sprite: s ? { path: leg.face === "left" ? s.left : s.right, ...fit(s.width, s.height, box) } : null,
    w: pet.w,
    h: pet.h,
    bubble: leg.bubble,
  };
}
```

```js
// How often legs are checked. This does arithmetic only; the panel is redrawn only
// when a pet starts a new leg. Motion itself is Herdr's native transition.
const CHECK_MS = 200;
const RETRY_MS = 60000; // a failed download is tried again after this long
// A load that has said nothing for this long is taken for dead (Herdr can stop a
// script without telling it) and is started again.
const STALL_MS = 120000;
const SNAP_MS = 150; // a change of place that is not a walk or a climb
const BUBBLE_H = 20;
const zoom = () => (Number(settings()?.zoom) > 0 ? Number(settings().zoom) : 1);
const artKey = (pet) => `${pet.type}/${pet.color}`;
// A cache entry that holds a loaded value: not one still loading, not a failure.
const loaded = (entry) => (entry && !entry.pending && !entry.error ? entry : null);

export default class Pets extends View {
  init(_p, cx) {
    const role = props()?.role;
    this.dialog = typeof role === "string" && Object.hasOwn(DIALOGS, role) ? DIALOGS[role] : null;
    this.closed = false;
    if (this.dialog) return this.dialog.init(this, cx);
    this.width = 220;
    this.height = 300;
    this.env = { width: this.width, height: this.height, floor: 0 };
    this.live = {}; // pet id -> the engine's pet
    this.art = {}; // "type/colour" -> sprites | { pending: <since> } | { error, at }
    this.scenes = {}; // "theme/kind/size" -> pictures | { pending } | { error, at }
    cx.timer.every(CHECK_MS, (cx) => this.check(cx));
    // keys.json can bind "pets.spawn", "pets.remove-all", "pets.size-<name>" and
    // "pets.theme-<name>".
    cx.spawn(async () => {
      for (;;) {
        const c = await nextCommand();
        try {
          const next = applyCommand(load(shared(KEY)), c);
          if (next) setShared(KEY, next);
          else if (c === "spawn") openPicker();
        } catch (e) {
          console.log(`pets: command ${c} failed: ${e?.message ?? e}`); // and keep listening
        }
      }
    });
  }

  // Herdr calls this when a dialog goes; work it left running checks the flag.
  async close() {
    this.closed = true;
  }

  // Loads in the background; `job` resolves with the value or rejects with the reason.
  want(cache, key, job, failed, cx) {
    const cur = cache[key];
    if (loaded(cur)) return;
    if (cur?.pending && Date.now() - cur.pending < STALL_MS) return;
    if (cur?.error && Date.now() - cur.at < RETRY_MS) return;
    const first = !cur;
    const mine = (cache[key] = { pending: Date.now() });
    cx.spawn(async (cx) => {
      let result;
      try {
        result = await job();
      } catch (e) {
        result = { error: String(e?.message ?? e), at: Date.now() };
        if (first) notify({ title: failed, body: result.error, level: "warning" });
      }
      if (cache[key] === mine) cache[key] = result; // not if a later try took over
      cx.notify();
    });
  }

  sceneKey(state) {
    return `${state.theme}/${settings()?.dark === false ? "light" : "dark"}/${state.size}`;
  }

  // A saved pet's loaded sprites, or null while there are none.
  sprites(p) {
    return loaded(this.art[artKey(p)])?.sprites ?? null;
  }

  check(cx) {
    const state = load(shared(KEY));
    let scene = null;
    if (state.theme !== "none") {
      const dark = settings()?.dark !== false;
      const key = this.sceneKey(state);
      this.want(this.scenes, key, () => loadTheme(state.theme, dark, state.size), `Couldn't load the ${state.theme} theme`, cx);
      scene = loaded(this.scenes[key]);
    }
    for (const p of state.pets) {
      this.want(this.art, artKey(p), () => loadPet(p.type, p.color), `Couldn't load ${p.name} the ${p.type}`, cx);
    }
    // Pets stand on a theme's ground only once its picture is there to stand on.
    this.env = { width: this.width, height: this.height, floor: scene ? floorFor(state.theme, state.size) : 0 };
    if (reconcile(this.live, state.pets, (p) => this.sprites(p), SIZES[state.size], this.env, Date.now(), Math.random)) cx.notify();
  }

  render(cx) {
    if (this.dialog) return this.dialog.render(this, cx);
    const t = theme();
    const now = Date.now();
    const state = load(shared(KEY));
    const box = SIZES[state.size];
    const scene = state.theme === "none" ? null : loaded(this.scenes[this.sceneKey(state)]);

    const root = div()
      .id("pets-panel")
      .relative()
      .size_full()
      .overflow_hidden()
      .bg(t.chrome)
      .on_size_change((size, cx) => {
        // The size comes in zoomed px, but everything here is drawn in unzoomed units.
        const width = size.width / zoom();
        const height = size.height / zoom();
        if (Math.abs(width - this.width) > 1 || Math.abs(height - this.height) > 1) {
          this.width = width;
          this.height = height;
          cx.notify();
        }
      })
      .on_mouse_down("right", () => openMenu({ menu: "ground" }));

    // Upstream repeats a theme's picture along the bottom edge.
    const tile = (pic) => {
      if (!(pic.width > 0)) return; // stepping by nothing would never reach the edge
      for (let x = 0; x < this.width; x += pic.width) {
        root.child(image(pic.path).absolute().left(x).top(this.height - pic.height).w(pic.width).h(pic.height));
      }
    };
    if (scene?.background) tile(scene.background);

    for (const p of state.pets) {
      const pet = this.live[p.id];
      if (!pet) continue; // the next check spawns it
      const d = drawing(pet, this.sprites(p), box, now);
      // The element is one box high whatever the sprite's height, and the picture
      // stands on its bottom: a pet's animations differ in height, and its feet must
      // not move when it changes from one to another.
      const w = d.sprite?.w ?? d.w;
      const h = d.sprite?.h ?? d.h;
      root.child(
        div()
          .id(`pet-${pet.id}`)
          .absolute()
          .w(w)
          .h(box)
          .left(d.x)
          .top(this.height - d.y - box)
          // The time left in the glide: right whether or not a redraw restarts it.
          .transition("left", { duration: d.moveX || SNAP_MS, easing: "linear" })
          .transition("top", { duration: d.moveY || SNAP_MS, easing: "linear" })
          .on_hover((over, cx) => {
            if (over && hover(pet, this.sprites(p), this.env, Date.now(), Math.random)) cx.notify();
          })
          .on_mouse_down("right", (_e, cx) => {
            cx.stop_propagation();
            openMenu({ menu: "pet", pet: pet.id });
          })
          .child(
            d.sprite
              ? image(d.sprite.path).absolute().left(0).top(box - h).w(w).h(h)
              : div().absolute().left(0).top(box - h).w(w).h(h).flex().items_center().justify_center()
                  .text_size(Math.round(h * 0.8)).child(PETS[pet.type].emoji),
          )
          .when(!!d.bubble, (el) =>
            el.child(
              div().absolute().left(0).top(box - h - BUBBLE_H).px(5).rounded(8).whitespace_nowrap()
                .bg(t.popover).border_1().border_color(t.border)
                .text_size(11).text_color(t.foreground).child(d.bubble),
            )),
      );
    }

    if (scene?.foreground) tile(scene.foreground);

    if (state.pets.length === 0) {
      root.child(
        div().absolute().inset_0().flex().items_center().justify_center().px(12)
          .text_size(12).text_color(t.dim).child("No pets yet. Click + to add one."),
      );
    }
    return root.child(
      div()
        .id("pets-add")
        .absolute().top(6).right(8).size(20).flex().items_center().justify_center().rounded(6)
        .text_size(15).text_color(t.muted).cursor_pointer()
        .hover((s) => s.bg(t.hover))
        .on_click(() => openPicker())
        .on_mouse_down("right", (_e, cx) => cx.stop_propagation())
        .child("+"),
    );
  }
}
```

Why the transition's duration is "time left in the leg": if a redraw part-way through a leg restarts the transition, the remaining time keeps the speed right; if it does not restart, the value is ignored. Either way the pet arrives on time.

Why the pet's element is one box high with the picture standing on its bottom: a pet's animations differ in height (the dog's idle is 115 x 90, its lie 140 x 75). If the element's `top` depended on the sprite's height, it would change at the start of every walk and glide for the whole walk, and the pet would sink into the ground or float.

````markdown
# herdr-pets

The [VS Code Pets](https://github.com/tonybaloney/vscode-pets) animals, living in a
panel of the [Herdr app](https://herdr.dev). Add a dog, a crab or a rubber duck, give
it a name, and it walks, runs, naps and reacts when you point at it.

![herdr-pets](preview.png)

The pets are decoration. They are not tied to your agents.

## Install

Ask your agent in Herdr to add this repository as a mod. It will copy the folder and
put the panel in your sidebar. To do it by hand:

```sh
cp -R mods/pets ~/.config/herdr-app/mods/pets
```

Then add a block for it to your layout (`~/.config/herdr-app/layouts/<name>.json`).
It sits well in the sidebar column, just above the footer:

```json
{ "id": "pets", "type": "block", "content": { "mod": "pets" }, "size": { "px": 110 } }
```

The mod does not dock itself: a panel Herdr docks on its own becomes a full-height
column, which is far more room than a few pets need. Give the block 160 px or more
if you want the cat, Totoro and the squirrel to climb the wall.

**What it does on your machine.** To get the sprites, the mod reads your editors'
extension folders (`~/.vscode/extensions`, `~/.vscode-insiders/extensions`,
`~/.cursor/extensions`, `~/.vscode-oss/extensions`) looking for VS Code Pets. For any
file it does not find there (every file, if the extension isn't installed) it runs
`curl` to download it from `raw.githubusercontent.com/tonybaloney/vscode-pets`. It
runs no other program. Sprites are cached in `~/.config/herdr-app/data/pets/`.

## Use

- **+** (top right of the panel) adds a pet: pick the animal, a colour and a name.
- **Point at a pet** and it reacts.
- **Right-click a pet** to rename or remove it.
- **Right-click the ground** to add a pet, pick a theme (forest, castle, beach,
  winter, autumn, library), pick a size (nano, small, medium, large) or remove all.
- For keys, bind any of `pets.spawn`, `pets.remove-all`, `pets.size-<nano|small|medium|large>`
  and `pets.theme-<none|forest|castle|beach|winter|autumn|library>` in
  `~/.config/herdr-app/keys.json`. The same commands work from a shell:
  `herdr-app do pets.size-small`.

Up to 20 pets. Your pets, the size and the theme are remembered. Pets start at
medium (55 px).

The first time you add a big pet (Totoro, the grey raccoon) it takes several seconds:
its mirrored sprites are made on your machine, in small steps so Herdr stays responsive.

## Where the art comes from

This repository contains code only. The sprites belong to the artists credited in
[NOTICE](NOTICE) and are never copied here.

- With VS Code Pets installed in VS Code, VS Code Insiders, Cursor or VSCodium, all
  27 pets are available.
- Without it, 23 pets are downloaded from the VS Code Pets repository on demand.
  Cat, frog, bunny and squirrel are not in that repository, so they need the
  extension installed.

Herdr cannot mirror an image, so the mod writes a left-facing copy of each sprite
into its cache. Those copies stay on your machine.
````

````markdown
# Pets

A small sidebar panel where the VS Code Pets animals live. The person adds pets with a +
button, each with an animal, a colour and a name. Pets idle, walk, run, lie down and
(cat, totoro, squirrel) climb the left wall, each following its own sequence from VS
Code Pets. They are decoration and know nothing about agents.

![Pets](preview.png)

## What you see

- One block in the sidebar column, just above its footer, 110 px high and as wide as
  the sidebar: `{ "id": "pets", "type": "block", "content": { "mod": "pets" }, "size": { "px": 110 } }`.
  `mod.json` is `{ "place": "none", "title": "Pets" }`: the mod does not dock itself,
  because a self-docked mod becomes a full-height column. Background `theme().chrome`.
- Pets stand on the bottom edge, or on the theme's ground line. Each is its animated
  GIF, drawn inside a square box and never enlarged: nano 30 px, small 40, medium 55,
  large 110. Default medium.
- A muted `+` (20 px, `theme().muted`) at top 6, right 8.
- With no pets, centred `theme().dim` 12 px text: "No pets yet. Click + to add one."
- With a theme (forest, castle, beach, winter, autumn, library) its background picture
  repeats along the bottom edge behind the pets and its foreground picture in front.
  Default: none.
- A pet whose sprites have not loaded shows as its emoji and stands still.

## How it behaves

- Pets ignore agent status entirely.
- Each pet starts in its start state and, when a state ends, picks the next at random
  from that state's list (repeats in a list are weights).
- Idle and lie hold 5 s, stand 6 s. Walk glides to the edge it faces: left edge 0,
  right edge 95% of the width less the sprite. Speed is the pet's speed (0 to 5) x 10
  px/s, x 0.7 to 1.3 chosen once per pet; run is 1.6 x. A speed-0 pet (rocky) holds.
- Wall: climb to 100 px at 10 px/s, hang 5 s, jump down at 50 px/s, land 1 s. The
  squirrel climbs to 30-80% of the panel height at 55 px/s and falls at 150 px/s. A
  panel too short to climb never picks the wall.
- Pointer over a pet on the ground: it stops where it is, plays `swipe` for 1.5 s with
  a bubble above it (👋; finley "Hi! 👋", horse "Neigh!", skeleton ☠️/🎃/🏴‍☠️ by colour,
  squirrel a random food), then resumes the state it was in.
- Click `+`: a dialog (420 x 540) with a search field, the 27 animals (emoji and
  name), the chosen animal's colours, a name field pre-filled with a random name, and
  Cancel / Add. Add fetches the sprites first; if that fails the pet is not added and
  a notification says why. At 20 pets the dialog says so and hides Add.
- Right-click a pet: popup with "<name> the <animal>", Rename… (a dialog), Remove.
- Right-click the ground: popup with Add pet…, Theme (7, the current one ticked), Size
  (4, ticked), Remove all.
- Commands `pets.spawn` (opens the dialog), `pets.remove-all`, `pets.size-<name>` and
  `pets.theme-<name>`. No keys are shipped.
- Pets, size and theme are saved; positions are not. After a restart pets start at a
  random spot.

## Built from

- `mods/pets/`: `main.js` (panel view; with `props().role` it is one of the dialogs),
  `dialogs.js` (picker, rename, menu), `roster.js` (keeps the pets on screen in step
  with the saved list and says what to draw; pure), `engine.js` (states to legs; pure),
  `pets.js` (generated tables for 27 pets from VS Code Pets 1.37.0), `store.js` (saved
  state; pure), `sources.js` (file names, URLs, sizes; pure), `gif.js` (GIF size and
  mirror; pure), `artcore.js` (fetch and cache, given its file and program access; pure)
  and `art.js` (hands `artcore.js` Herdr's `exec`, `fs/promises`, `home`, `appHome`).
- A **leg** is `{ state, sprite, face, fromX, toX, fromY, toY, start, duration, bubble }`.
  Each pet is an absolutely positioned `div`, one size-box high, at the leg's end, with
  its picture standing on the bottom of that box. `.transition("left", …)` gets the time
  left in the leg when the leg moves sideways and `.transition("top", …)` when it moves
  up or down; the other axis gets 150 ms.
- `cx.timer.every(200)` checks for finished legs and calls `cx.notify()` only when a
  pet starts a new one.
- `herdr`: `shared("pets")` / `setShared("pets", { pets: [{ id, type, color, name }], size, theme })`,
  `openOverlay` (dialog and popup of this same mod), `closeOverlay`, `notify`,
  `nextCommand`, `theme`, `settings` (`zoom`, `dark`), `props`, `exec`, `home`,
  `appHome`; `fs/promises` for binary read and write.
- Art: none shipped. `artcore.js` copies `<colour>_<state>_8fps.gif` from the newest
  `tonybaloney.vscode-pets-*` across `~/.vscode/extensions`,
  `~/.vscode-insiders/extensions`, `~/.cursor/extensions` and `~/.vscode-oss/extensions`.
  For a file not found there it runs
  `curl -sL --proto =https --retry 2 --connect-timeout 10 --max-time 20 --max-filesize 20000000 -o <side file> -w %{http_code}`
  against `https://raw.githubusercontent.com/tonybaloney/vscode-pets/1.37.0/media/`:
  200 is kept, 404 means the pet has no such animation, anything else is an error.
  Files go to `~/.config/herdr-app/data/pets/<type>/`, each with a mirrored `.left.gif`
  written by `gif.js`, and a `<colour>.json` listing them. Theme pictures:
  `backgrounds/<theme>/{background,foreground}-{dark,light}-<size>.png`.
- It reads those extension folders, runs `curl` (for any file the installed extension
  does not have; for every file without the extension) and reaches
  `raw.githubusercontent.com`. Tell the person before adding it.

## Watch out

- There is no flip or mirror in the UI kit. Left-facing sprites must be files.
- Herdr stops a script that runs about half a second without a break (400 ms passes,
  800 ms is stopped), and `try`/`catch` does not see it. Mirroring a big sprite
  (Totoro's is 27 frames of 600 x 396) takes seconds. So `gif.js` works in steps of
  16384 pixels, about 5 ms each, and `artcore.js` awaits a real host call
  (`fs.exists`) between them at least every 25 ms. Without this the load dies silently
  and the dialog says "Fetching…" for ever.
- A load that has said nothing for two minutes is started again.
- Herdr reloads a mod only when a file inside its own `mods/` folder changes. A
  symlinked mod folder keeps running the old code.
- The panel is 110 px high. Climbing needs the climb height (100 px) plus the pet's
  height: about 160 px at medium. In a shorter panel pets never pick the wall.
- A mod's `fetch` returns only text or JSON, so binary downloads need `curl`.
- Cat, frog, bunny and squirrel are not in the VS Code Pets GitHub repository. Without
  the extension they are greyed out in the dialog and cannot be added.
- The dog art is CC BY-ND: keep its files unmodified apart from the cached mirror, and
  never commit any sprite.
- Sizes from `on_size_change` are zoomed px; divide by `settings().zoom`.
- Colours with a space (`socks black`) use an underscore in file names.
- Not every pet has every animation (there may be no `swipe` file). A missing one
  falls back to idle, then walk.
- Give the transition the time left in the leg, not its full length, so a redraw
  part-way through cannot slow the pet.
- A pet's animations differ in height (a dog lying down is shorter than one sitting).
  Keep the pet's element one box high and stand the picture on its bottom, or the pet
  sinks into the ground or floats when it changes animation.
- Every copy of the mod shares its modules, and Herdr stops a closed dialog's work
  part-way. Never make one load wait on another's promise: it may never settle. Each
  load downloads into a side file of its own and puts only whole files in place.
- Treat downloaded bytes as untrusted: a GIF with a bad code or a picture claiming
  width 0 must be rejected, because a loop on Herdr's thread freezes the window.
- Pets stand on a theme's ground only once its picture has loaded.
- The overlays open `mod: "pets"`. If the folder is renamed on install, change `MOD`
  in `dialogs.js` and `DATA_REL` in `artcore.js`.
- No ball, no pets chasing each other, no falling snow/leaves/stars, no saved positions.
````
